
# مشروع إنشاء صفحة HTML

## فكرة المشروع
إنشاء صفحة ويب شخصية بسيطة باللغة العربية للتدرب على تصميم صفحات الويب.

## محتويات المشروع
- index.html: الصفحة الرئيسية للموقع.
- README.md: ملف يشرح فكرة المشروع ومحتوياته.

## التقنيات المستخدمة
- HTML: لبناء هيكل الصفحة.
- CSS: لتنسيق الألوان والخطوط والأقسام.

## أقسام الموقع
1. من أنا؟
2. هواياتي واهتماماتي.
3. تواصل معي.

## طريقة تشغيل المشروع
فتح ملف index.html باستخدام أي متصفح إنترنت.

## الهدف من المشروع
التعرف على أساسيات إنشاء صفحات الويب وتنسيقها واستخدام التعليقات داخل الكود.
